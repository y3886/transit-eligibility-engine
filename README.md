## 📌 תקציר הפרויקט (Overview)

מנוע תשתיתי (Backend Microservice) וצינור עיבוד נתונים (ETL Pipeline) עצמאי, שפותח עבור הרשות הארצית לתחבורה ציבורית במסגרת רפורמת **"צדק תחבורתי"**.

המערכת מאפשרת לאזרח להזין כתובת מגורים בטקסט חופשי (Unstructured Hebrew Text), מפענחת את שם היישוב בדיוק מרבי, ומחזירה בתוך חלקיק שנייה תשובת זכאות מנומקת להנחת 50% על מנויי "חופשי חודשי" ברב-קו.

---

## 🏗️ ארכיטקטורת המערכת (Architecture)

המערכת פועלת בארכיטקטורה מופרדת (Decoupled Two-Engine Architecture) המבדילה בין שלב פענוח הכתובת לשלב ההכרעה העסקית:

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   שכבת מקורות מידע רשמיים (CBS Raw Data)                │
│  - מדד פריפריאליות 2020 (לוח 2)  - מדד חברתי-כלכלי 2021 (לוחות א1, ב)  │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼ (ETL Pipeline & Data Quality Gates)
┌────────────────────────────────────────────────────────────────────────┐
│               קובץ מאסטר מנוהל גרסה (localities_master.json)           │
│               100% כיסוי ארצי (1,213 יישובים) + מנגנון ירושה מבוקר     │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼ (In-Memory Load at Startup)
┌────────────────────────────────────────────────────────────────────────┐
│                  מנוע השירות (Eligibility Microservice)                │
│                                                                        │
│   ┌──────────────────────────────┐    ┌────────────────────────────┐  │
│   │   מנוע 1: פענוח כתובת        │    │    מנוע 2: קביעת זכאות     │  │
│   │   (Address Resolver)         │───►│    (Eligibility Engine)    │  │
│   │   נרמול, Exact, Fuzzy מכויל  │    │    פריפריה <= 5 או סוציו <= 5  │  │
│   └──────────────────────────────┘    └────────────────────────────┘  │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ (JSON API Response)
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                  ממשק משתמש / צרכני API (Client Frontend)              │
└────────────────────────────────────────────────────────────────────────┘
